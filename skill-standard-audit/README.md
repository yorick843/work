# skill-standard-audit

Скилл для проверки существующих скиллов на соответствие внутреннему стандарту написания
скиллов и приведения их к нему.

**Версия:** см. `metadata.version` в `SKILL.md` — это источник истины; README номер не дублирует, чтобы не отставать.

## Что делает

Определяет класс скилла (одноразовый или сессионный) и считает бюджет контекста по его
порогу, находит битые и вложенные ссылки, файлы-сироты, конкуренцию
описаний между скиллами и разошедшиеся копии общих файлов, проверяет наличие сценариев
прогона. Выдаёт отчёт с приоритетами по цене нарушения и планом правок. По согласию —
проводит правку по процедурам из `references/migration-playbook.md`.

## Установка

Загрузить папку целиком (или `.skill`-архив) через настройки Claude. Имя папки должно
оставаться `skill-standard-audit` — оно совпадает с полем `name` и при переименовании
скилл не загрузится.

## Ручной запуск валидатора

```bash
python3 scripts/check-skill.py <путь-к-скиллу> [<ещё-скилл> ...]
```

Несколько путей за раз включают сравнение скиллов между собой. Код возврата 1 — есть ошибки.

## Границы применимости

- Валидатор проверяет форму, не содержание: качество описания, уместность степени свободы
  и верность предметных правил оценивает человек по чек-листу раздела 15 стандарта.
- Оценка токенов эвристическая, точность около ±20%.
- Скилл не создаёт скиллы с нуля и не переписывает предметные правила чужого скилла.

## Состав

| Путь | Назначение |
|---|---|
| `SKILL.md` | инструкции для модели |
| `references/standard.md` | сам стандарт написания скиллов |
| `references/migration-playbook.md` | процедуры правки: разбиение, слияние, навигация, описание, гигиена |
| `references/eval-templates.md` | как писать и прогонять сценарии |
| `scripts/check-skill.py` | валидатор механической части стандарта, включая сверку README «Состав» с набором файлов |
| `scripts/selftest.py` | самопроверка согласованности этого скилла |
| `evals/` | сценарии выдачи и триггерные запросы |
