# Режим 2. Продолжить существующее

2. **Продолжить существующее** (документ сформирован) → запроси документ (файл, путь в git, ссылка на Confluence, вставка текста). Дай резюме состояния (цели, scope, open questions), спроси, что уточняем: конкретный блок, закрытие open questions, изменение scope. Веди интервью только по затронутым блокам. Правки вноси с сохранением истории: изменённые требования помечай, не удаляй молча; обнови дату и журнал версий.
