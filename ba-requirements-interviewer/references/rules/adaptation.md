# Правило 24. Адаптация глубины и ширины

24. **Адаптация глубины и ширины.**
    - *Глубина:* полный проход — продукты и платформы. Мелкая фича (критерий и сжатый ритуал — шаг 5, п.2) проходит не блоки, а список вопросов — это её плановый набор, по нему идёт самопроверка:

      | Вопрос | Зачем | Как задавать |
      |---|---|---|
      | 1.1 проблема | секция 2 | обычно закрыт питчем |
      | 1.3 метрика успеха | секции 2, 13; правило 21 | отдельно |
      | 1.5 заказчик | карта участников; после него — PQ-1 и PQ-2 | пакет |
      | 2.1 пользователи | проверка критерия «один тип пользователя» | пакет |
      | основной сценарий — один вопрос блока 4 или профиля по сути фичи | секция 6 | отдельно |
      | 5.1 точка входа, 5.6 видимость — если есть интерфейс | секция 7 | пакет |
      | 7.1 регуляторика — страховка | проверка критерия «нет регуляторных вопросов» | пакет |
      | 9.5 чувствительность операций, ИБ — страховка | права доступа, подтверждение операций | пакет |
      | 10.2 вне периметра | секция 5 | пакет |
      | 10.4 риски | секция 12 | отдельно |
      | 11.2 go/no-go | секция 13 | пакет |

      Каждый блок ядра представлен хотя бы одним вопросом. Вопросы на рассуждение — отдельно, по одному (однородность пакета, `references/pace-and-batching.md`). Список ссылается на номера банка: при перенумерации банка сверяй его.
    - *Ширина:* доменный профиль из `references/domain-profiles.md` (А розничный брокеридж / Б корпоративные продукты / В операционные системы / Г системы обслуживания клиентов), профили комбинируются.
    - *Фиксация причины — в момент решения, а не постфактум.* Как только плановый набор сокращается (шаг 5, п.1–2) или блок пропускается по ходу, запиши причину сразу: масштаб инициативы, доменный профиль, отсутствие UI, команда стейкхолдера, досрочное завершение. При формировании документов причина берётся из этой записи, а не восстанавливается по памяти.
    - *Пропуск по инициативе агента требует подтверждения.* Решил, что блок неприменим (например, блок 5 при отсутствии интерфейса) — это твоя гипотеза: предъяви её одной строкой и получи согласие («судя по описанию, интерфейса у фичи нет — пропускаю блок?»). Пропуск по команде стейкхолдера подтверждения не требует.
