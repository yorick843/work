# brd-digest-backend

Скилл готовит из BRD по шаблону `ba-requirements-interviewer` выжимку для бекового аналитика (БА+СА) и бекового тестировщика. Правила работы лежат в `SKILL.md`, здесь — только установка и границы.

**Установка.** Загрузи `.zip` или `.skill` в хранилище скиллов; внутри одна папка `brd-digest-backend/` с `SKILL.md` в корне.

**Что нужно на входе.** Готовый BRD по шаблону интервьюера. Для режима «что изменилось» — две версии.

**Что на выходе.** Файл markdown: суть и бизнес-смысл, процессы, разделы A–G для бека, «Стыки», «Уточнить», подраздел для тестировщика, «Опущено».

**Соседний скилл.** `brd-digest-frontend` (фронтовая выжимка) использует то же ядро `references/core/` и `scripts/brd_tools.py`. Копии ядра обязаны совпадать побайтово; правка ядра вносится в оба скилла с подъёмом строки «Версия ядра».

**Выбор шаблона выжимки.** Каркас собран по типовым структурам системной документации и трассировки «требование → проверка»; обоснование и источники — в сопроводительном отчёте к скиллу.

**Фикстуры.** `evals/fixtures/` содержит реальные BRD проекта; убери папку перед передачей скилла за пределы команды (`selftest.py` без неё пропускает проверки на данных).

**Проверка.** `python scripts/selftest.py`.

## Состав

Карта ведётся вместе с пакетом: любая правка, меняющая набор файлов, обновляет эту таблицу в той же правке и попадает в `CHANGELOG.md`. Сверку с диском делает `check-skill.py` из `skill-standard-audit`.

**Файлы пакета**

| Путь | Назначение |
|---|---|
| `SKILL.md` | инструкции для модели: порядок работы, принципы выжимки, проверка перед выдачей |
| `references/core/` | общее ядро для скиллов `brd-digest-*`, копии побайтово одинаковы (строка «Версия ядра» в каждом файле) |
| `references/core/brd-reading.md` | карта секций BRD, ID, теги достоверности, смешанные требования |
| `references/core/digest-frame.md` | каркас выжимки, формат строки, пометки, «Уточнить», подраздел для тестировщика, «Опущено» |
| `references/core/change-detection.md` | режим «что изменилось» при двух версиях BRD |
| `references/profile-backend.md` | профиль бека: слой, разделы A–G, чек-листы пробелов, «Стыки», категории границ для QA |
| `references/worked-example-backend.md` | образец выжимки на вымышленном примере |
| `scripts/brd_tools.py` | `ids`, `diff`, `coverage`; общий для `brd-digest-*`; только стандартная библиотека |
| `scripts/selftest.py` | самопроверка: ссылки, маркеры ядра, скрипт на фикстурах |
| `evals/evals.json` | пять сценариев выдачи |
| `evals/trigger-evals.json` | 20 запросов на срабатывание, из них 10 близких промахов |
| `evals/fixtures/` | реальные BRD проекта (v0.2, v1.0, черновик v0.1); данные проекта, в `.skill` не попадают |
| `CHANGELOG.md` | история правок |

**Данные**

| Что | Формат | Где |
|---|---|---|
| Вход | BRD по шаблону `ba-requirements-interviewer`, markdown; для сравнения — две версии | передаёт пользователь |
| Выход | выжимка, markdown, каркас из `references/core/digest-frame.md`; имя файла — по названию BRD и версии | рабочая папка, затем отправка пользователю |
| Выход скрипта | таблицы markdown или `--json`; код возврата 0 — норма, 1 — расхождения, 2 — вход не BRD или неверные аргументы | stdout |
| Данные проекта | `evals/fixtures/` | убрать перед передачей за пределы команды |
